# vivvy-core

Single-machine, high-performance vector index engine for Vivvy.

## Features

- **HNSW Vector Index**: Fast approximate nearest neighbor search.
- **Roaring Bitmaps**: Metadata filtering with high performance.
- **Durable Storage**: Write-Ahead Logging (WAL) and segment manifest recovery.
- **64-bit ID Preservation**: Safe explicit ID mapping.
- **Concurrency**: Lock-free reads and efficient concurrent inserts.
